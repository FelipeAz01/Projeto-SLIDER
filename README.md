# ✅ Projeto SLIDES


## 📘 Descrição
O projeto Slides é uma apresentação interativa de destinos turísticos. Ele exibe imagens de locais icônicos como Veneza, Bali, Paris e Roma, permitindo ao usuário navegar entre os destinos com setas direcionais e interagir com informações adicionais sobre cada local.

## 📋 Gerenciar Tarefas
- [x] Exibição de imagens: Cada slide apresenta uma imagem de fundo representando um destino.
- [x] Título e descrição: Título com o nome do destino e um breve parágrafo com descrição.
- [x] Botões de interação: <br>
      - Saiba mais: Direciona para uma página com mais informações sobre o destino.
      - Acessar: Pode levar a um site externo ou conteúdo específico do destino.
- [x] Navegação entre slides:<br>
      -Setas para a direita e esquerda permitem alternar entre os destinos em um loop infinito.

## 🛠️ Tecnologias Utilizadas

- HTML: 🌐📝 Estrutura do projeto.
- CSS: 🎨📐 Estilização visual dos elementos e layout responsivo.
- JavaScript: 💻✨ Lógica de navegação entre slides e interatividade dos botões.

## Como Usar ? 🤔

1. Visualizar slides: Navegue entre os destinos clicando nas setas de navegação localizadas no canto inferior esquerdo.

2. Explorar mais:

- Clique no botão "Saiba mais" para acessar informações detalhadas sobre o destino. (Em construção)

- Clique em "Acessar" para ser redirecionado para conteúdos externos relacionados.(Em construção)
